Let $k$ be a positive integer and set $n = 2k + 1$. Prove that $n$ is a prime number if and only if the following holds: there is a permutation $a_1, \ldots, a_{n-1}$ of the numbers $1, 2, \ldots, n - 1$ and a sequence of integers $g_1, g_2, \ldots, g_{n-1}$ such that $n$ divides $g_i a_i - a_{i+1}$ for every $i \in \{1, 2, \ldots, n - 1\}$, where we set $a_n = a_1$.
