of an n ˆ n board such that each integer is written in exactly one cell and each cell contains

contained in exactly one d ˆ d sub-board.
    We say that n is a cool number if the integers can be written on the n ˆ n board such that,
for each integer d with d | n and 1 < d < n, in the d-division of the board, the sum of the
integers written in each d ˆ d sub-board is not a multiple of d.
    Determine all even cool numbers.
