Let $\mathbb{Z}_{>0}$ denote the set of positive integers. Let $f \colon \mathbb{Z}_{>0} \to \mathbb{Z}_{>0}$ be a function satisfying the following property: for all $m$, $n \in \mathbb{Z}_{>0}$, the equation
\[
f(mn)^2 = f(m^2)f(f(n))f(mf(n))
\]
holds if and only if $m$ and $n$ are coprime.

For each positive integer $n$, determine all the possible values of $f(n)$.
