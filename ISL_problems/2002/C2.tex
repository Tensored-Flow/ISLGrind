For an odd positive integer $n$, the unit squares of an $n \times n$ chessboard are colored alternately black and white, with the four corners colored black. A \emph{tromino} is an $L$-shape formed by three connected unit squares. For which values of $n$ is it possible to cover all the black squares with nonoverlapping trominos? When it is possible, what is the minimum number of trominos needed?
