Given a sequence $a_1, a_2, \ldots, a_n$ of real numbers. For each $i$ ($1 \leq i \leq n$) define
\[
d_i = \max\{a_j : 1 \leq j \leq i\} - \min\{a_j : i \leq j \leq n\}
\]
and let
\[
d = \max\{d_i : 1 \leq i \leq n\}.
\]
(a) Prove that for arbitrary real numbers $x_1 \leq x_2 \leq \ldots \leq x_n$,
\[
\max\{|x_i - a_i| : 1 \leq i \leq n\} \geq \frac{d}{2}. \tag{1}
\]
(b) Show that there exists a sequence $x_1 \leq x_2 \leq \ldots \leq x_n$ of real numbers such that we have equality in $(1)$.
