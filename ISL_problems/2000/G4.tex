Let $A_1 A_2 \dots A_n$ be a convex polygon, $n \geq 4$. Prove that $A_1 A_2 \dots A_n$ is cyclic if and only if to each vertex $A_j$ one can assign a pair $(b_j, c_j)$ of real numbers, $j = 1, 2, \dots, n$, such that
\[ A_i A_j = b_j c_i - b_i c_j \quad \text{for all } i, j \text{ with } 1 \leq i < j \leq n. \]
