Let $T$ denote the set of all ordered triples $(p, q, r)$ of nonnegative integers. Find all functions $f : T \to \mathbb{R}$ such that
\[ f(p, q, r) = \begin{cases} 0 & \text{if } pqr = 0, \\ 1 + \dfrac{1}{6}\big( f(p+1, q-1, r) + f(p-1, q+1, r) \\ \quad + f(p-1, q, r+1) + f(p+1, q, r-1) \\ \quad + f(p, q+1, r-1) + f(p, q-1, r+1) \big) & \text{otherwise.} \end{cases} \]
