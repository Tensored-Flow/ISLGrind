Let $\mathcal{V}$ be a finite set of points in the plane. We say that $\mathcal{V}$ is \emph{balanced} if for any two distinct points $A, B \in \mathcal{V}$, there exists a point $C \in \mathcal{V}$ such that $AC = BC$. We say that $\mathcal{V}$ is \emph{center-free} if for any distinct points $A, B, C \in \mathcal{V}$, there does not exist a point $P \in \mathcal{V}$ such that $PA = PB = PC$.

\begin{enumerate}
\item[(a)] Show that for all $n \geq 3$, there exists a balanced set consisting of $n$ points.
\item[(b)] For which $n \geq 3$ does there exist a balanced, center-free set consisting of $n$ points?
\end{enumerate}
