Let $\mathbb{Z}_{>0}$ denote the set of positive integers. Consider a function $f \colon \mathbb{Z}_{>0} \to \mathbb{Z}_{>0}$. For any $m, n \in \mathbb{Z}_{>0}$ we write $f^n(m) = \underbrace{f(f(\ldots f(m) \ldots))}_{n}$. Suppose that $f$ has the following two properties:
\begin{itemize}
\item[(i)] If $m, n \in \mathbb{Z}_{>0}$, then $\dfrac{f^n(m) - m}{n} \in \mathbb{Z}_{>0}$;
\item[(ii)] The set $\mathbb{Z}_{>0} \setminus \{ f(n) \mid n \in \mathbb{Z}_{>0} \}$ is finite.
\end{itemize}
Prove that the sequence $f(1) - 1, f(2) - 2, f(3) - 3, \ldots$ is periodic.
