Let $a, b$ be natural numbers with $1 \leq a \leq b$, and $M = \left[\frac{a+b}{2}\right]$. Define the function $f : \mathbb{Z} \to \mathbb{Z}$ by
\[ f(n) = \begin{cases} n+a, & \text{if } n < M, \\ n-b, & \text{if } n \geq M. \end{cases} \]
Let $f^1(n) = f(n)$, $f^{i+1}(n) = f(f^i(n))$, $i = 1, 2, \ldots$. Find the smallest natural number $k$ such that $f^k(0) = 0$.
