Assume that a function $f \colon \mathbb{R} \to \mathbb{R}$ satisfies the following condition:
\[
\text{For every } x, y \in \mathbb{R} \text{ such that } \bigl(f(x) + y\bigr)\bigl(f(y) + x\bigr) > 0, \text{ we have } f(x) + y = f(y) + x.
\]
Prove that $f(x) + y \leq f(y) + x$ whenever $x > y$.
