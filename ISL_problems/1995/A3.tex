Let $n$ be an integer, $n \geq 3$. Let $a_1, a_2, \ldots, a_n$ be real numbers such that $2 \leq a_i \leq 3$ for $i = 1, 2, \ldots, n$. If $s = a_1 + a_2 + \cdots + a_n$, prove that
\[ \frac{a_1^2 + a_2^2 - a_3^2}{a_1 + a_2 - a_3} + \frac{a_2^2 + a_3^2 - a_4^2}{a_2 + a_3 - a_4} + \cdots + \frac{a_n^2 + a_1^2 - a_2^2}{a_n + a_1 - a_2} \leq 2s - 2n. \]
