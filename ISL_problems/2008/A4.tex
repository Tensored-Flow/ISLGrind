For an integer $m$, denote by $t(m)$ the unique number in $\{1, 2, 3\}$ such that $m + t(m)$ is a multiple of $3$. A function $f : \mathbb{Z} \to \mathbb{Z}$ satisfies $f(-1) = 0$, $f(0) = 1$, $f(1) = -1$ and
\[
f(2^{n} + m) = f(2^{n} - t(m)) - f(m) \quad \text{for all integers } m, n \geq 0 \text{ with } 2^{n} > m.
\]
Prove that $f(3p) \geq 0$ holds for all integers $p \geq 0$.
